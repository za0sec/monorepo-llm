                            Unidad 2 - Embeddings
Representación vectorial del texto
Un embedding es una representación numérica de un elemento, como una palabra, una
oración o un documento. Se expresa como un vector, es decir, una lista ordenada de
números. Un modelo transforma los elementos de texto en puntos de un espacio continuo.
Esa representación permite aplicar operaciones matemáticas al texto y comparar sus
representaciones.

Embeddings estáticos y contextuales
Un embedding estático, como el de una palabra en Word2Vec, conserva el mismo vector
para esa palabra una vez entrenado. El contexto del corpus ayuda a aprenderlo durante el
entrenamiento. En cada uso posterior, el modelo consulta el vector fijo.

Un embedding contextual se calcula para una aparición concreta. En «fui al banco a retirar
dinero» y «me senté en el banco de la plaza», las palabras vecinas permiten construir
representaciones distintas para «banco». La clase ilustra esta diferencia con un ejemplo de
«pizza» en dos oraciones.

Similitud coseno
Cómo comparar dos embeddings
Dados dos textos, primero se obtiene un vector para cada uno usando el mismo modelo de
embeddings. La similitud coseno compara la dirección de los dos vectores mediante el
coseno del ángulo que forman. Para calcularla, se divide el producto escalar por el producto
de las normas euclidianas.



                   similitud coseno(a, b) = (a · b) / (‖a‖ × ‖b‖)
